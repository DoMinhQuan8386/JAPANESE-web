Mô tả chi tiết về dự án:

## 🚀 Cài Đặt & Khởi Chạy (Getting Started)

### Yêu Cầu Tiên Quyết (Prerequisites)
Đảm bảo máy tính của bạn đã cài đặt các công cụ sau:
- **Node.js**: Phiên bản `>= 18.x.x` ([Tải tại đây](https://nodejs.org/))
- **npm** (hoặc `yarn`, `pnpm`): Phiên bản `>= 9.x.x`
- **Git**: Phiên bản mới nhất ([Tải tại đây](https://git-scm.com/))

### Các Bước Cài Đặt (Installation)

1. **Clone repository về máy**:
   ```bash
   git clone https://github.com/username/project-name.git
   cd project-name
   ```

2. **Cài đặt các gói phụ thuộc (Dependencies)**:
   ```bash
   npm install
   # Hoặc nếu dùng yarn:
   # yarn install
   ```

3. **Thiết lập biến môi trường**:
   ```bash
   cp .env.example .env
   ```

4. **Khởi chạy môi trường phát triển (Development Mode)**:
   ```bash
   npm run dev
   ```
   Mở trình duyệt và truy cập: `http://localhost:3000`

### Biến Môi Trường (Environment Variables)

File `.env` mẫu cần có các cấu hình cơ bản:

```env
PORT=3000
NODE_ENV=development
DATABASE_URL=mongodb://localhost:27017/my_database
JWT_SECRET=your_super_secret_key_here
API_BASE_URL=https://api.example.com
```

> [!WARNING]
> Tuyệt đối **không** commit file `.env` chứa mật khẩu thật lên GitHub. Chỉ chia sẻ file `.env.example`.

## 🤝 Hướng Dẫn Đóng Góp (Contributing)

Đóng góp của cộng đồng luôn được hoan nghênh và trân trọng! Hãy làm theo quy trình dưới đây:

1. **Fork** dự án về tài khoản của bạn.
2. Tạo nhánh tính năng mới (`git checkout -b feature/AmazingFeature`).
3. Commit thay đổi theo chuẩn ([Conventional Commits](#quy-chuẩn-git-commit-conventional-commits)):
   ```bash
   git commit -m 'feat: thêm hiệu ứng chuyển màu cho thẻ dịch vụ'
   ```
4. Đẩy mã nguồn lên GitHub (`git push origin feature/AmazingFeature`).
5. Mở một **Pull Request (PR)** và mô tả chi tiết nội dung đã thay đổi.

### Quy Chuẩn Git Commit (Conventional Commits)
- `feat:` Thêm tính năng mới (Feature)
- `fix:` Sửa lỗi (Bug fix)
- `docs:` Thay đổi hoặc bổ sung tài liệu (Documentation)
- `style:` Thay đổi định dạng code (khoảng trắng, dấu chấm phẩy, không ảnh hưởng logic)
- `refactor:` Tái cấu trúc code (không thêm tính năng, không sửa lỗi)
- `test:` Bổ sung hoặc chỉnh sửa Unit Tests
- `chore:` Cập nhật các tác vụ bảo trì, build tool, dependencies

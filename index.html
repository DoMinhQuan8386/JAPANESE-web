Hoạt Động 4: "Refactoring Performance" (Tối Ưu Hiệu Năng GPU)

Giảng viên hướng dẫn thay đổi thuộc tính top/left thành transform: translate để AI và lập trình viên sinh ra code không gây giật lag trên điện thoại:

Kém Hiệu Năng (Lag Mobile) 
/* ❌ Dùng top/left gây Reflow/Layout */
.card-item {
  position: relative;
  top: 0;
  transition: top 0.3s ease;
}

.card-item:hover {
  top: -5px; 
  /* Buộc CPU tính lại tọa độ
     toàn bộ cây DOM -> Tụt FPS */
}
Đã Refactor (Mượt 60-120 FPS) 
/* ✅ Dùng transform đẩy lên GPU */
.card-item {
  transform: translateY(0);
  transition: transform 0.3s cubic-bezier(...);
  will-change: transform;
}

.card-item:hover {
  transform: translateY(-5px);
  /* Bỏ qua Layout & Paint!
     GPU Composite xử lý siêu mượt */
}
Bản chất kiến trúc: Thuộc tính top/left kích hoạt chu kỳ đầy đủ: Layout → Paint → Composite trên Main Thread (CPU). Khi refactor sang transform: translateY(), trình duyệt bỏ qua bước Layout và Paint, giao thẳng cho GPU Compositor Thread xử lý, triệt tiêu giật lag trên thiết bị di động.

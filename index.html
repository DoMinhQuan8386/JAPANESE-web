Tôi là sinh viên ngành Công nghệ thông tin tại Trường Đại học Lạc Hồng.

Tôi yêu thích lập trình Web và luôn muốn tìm hiểu những công nghệ mới để nâng cao kỹ năng của bản thân. Bên cạnh việc học lập trình, tôi cũng có sở thích học tiếng Nhật và khám phá văn hóa Nhật Bản.

Mục tiêu

Mục tiêu của tôi là xây dựng nền tảng lập trình Web vững chắc, đặc biệt là HTML, CSS và JavaScript, đồng thời phát triển khả năng làm việc với Git và GitHub.

Kỹ năng

  • HTML5 - Xây dựng cấu trúc website
  • CSS3 - Thiết kế giao diện website
  • JavaScript - Tạo tính năng tương tác
  • Python - Lập trình cơ bản
  • SQL Server - Quản lý cơ sở dữ liệu
  • Git & GitHub - Quản lý mã nguồn

Dịch vụ

🌐 Thiết kế Web

Xây dựng giao diện website bằng HTML và CSS với bố cục rõ ràng và dễ sử dụng.

🎨 Thiết kế giao diện

Tạo giao diện hiện đại, màu sắc hài hòa và phù hợp với nhiều kích thước màn hình.

💻 Lập trình

Sử dụng JavaScript để xây dựng các chức năng tương tác cơ bản cho website.

📚 Hỗ trợ học tập

Xây dựng các website hỗ trợ học tập, ví dụ như website học tiếng Nhật cơ bản.

  • Học bảng chữ cái Hiragana.

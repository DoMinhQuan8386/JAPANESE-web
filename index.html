Giới thiệu bản thân

Xin chào! Tôi là một lập trình viên Front-end với niềm đam mê xây dựng giao diện web hiện đại, trực quan và chuẩn tiếp cận (Web Accessibility). Hiện tại tôi đang tập trung trau dồi HTML5, CSS3, JavaScript và các công nghệ web nền tảng.

Mục tiêu của tôi là tạo ra những trải nghiệm người dùng mượt mà, tối ưu hiệu suất và tuân thủ các tiêu chuẩn code sạch (Clean Code).

Dịch vụ cung cấp

💻

Thiết kế & Phát triển Web

Xây dựng website chuẩn Semantic HTML5, CSS3 hiện đại, tối ưu SEO và tốc độ tải trang nhanh chóng.

📱

Giao diện Responsive

Đảm bảo giao diện hiển thị tối ưu, sắc nét và tương thích mượt mà trên mọi thiết bị Desktop, Tablet và Mobile.

⚡

Tối ưu hóa hiệu suất

Cải thiện chỉ số Core Web Vitals, tối ưu tài nguyên hình ảnh và mã nguồn giúp trải nghiệm người dùng mượt mà nhất.

🛠️

Bảo trì & Nâng cấp UI

Sửa lỗi hiển thị trên đa trình duyệt, cập nhật tính năng mới và chuẩn hóa theo tiêu chuẩn tiếp cận Web (a11y).

Dịch vụ cung cấp

🌐 Thiết kế Web

Xây dựng giao diện website bằng HTML và CSS với bố cục rõ ràng và dễ sử dụng.

🎨 Thiết kế giao diện

Tạo giao diện hiện đại, màu sắc hài hòa và phù hợp với nhiều kích thước màn hình.

💻 Lập trình

Sử dụng JavaScript để xây dựng các chức năng tương tác cơ bản cho website.

📚 Hỗ trợ học tập

Xây dựng các website hỗ trợ học tập, ví dụ như website học tiếng Nhật cơ bản.

Dự án tiêu biểu

🇯🇵 Tiếng Nhật

Website học tiếng Nhật cơ bản

Dự án hỗ trợ người mới bắt đầu học tiếng Nhật với giao diện trực quan và dễ tiếp thu.

Nội dung website:

  • Học bảng chữ cái Hiragana & Katakana.
  • Ô học thuộc giúp luyện nhớ mặt chữ.
  • Học từ vựng và ngữ pháp cơ bản N5.

Công nghệ: HTML5, CSS3, JavaScript

🛒 E-Commerce

Website Thương mại điện tử Mini

Website bán hàng trực tuyến mô phỏng hệ thống danh mục sản phẩm và giỏ hàng hiện đại.

Chức năng chính:

  • Hiển thị và phân loại sản phẩm theo danh mục.
  • Xem chi tiết thông tin và giá sản phẩm.
  • Thêm sản phẩm và quản lý số lượng giỏ hàng.

Công nghệ: HTML5, CSS3, JavaScript
